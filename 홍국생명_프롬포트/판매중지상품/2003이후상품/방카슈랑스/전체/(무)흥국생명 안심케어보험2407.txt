[DOWNLOAD 생성 규칙]

- 위 목록에 명시된 문서만 DOWNLOAD 단계로 생성한다.
- 각 DOWNLOAD는 [5. 상품 공시 다운로드] 표에서 지정된 판매기간 행과 문서 열이 교차하는 PDF 링크를 대상으로 생성한다.
- 상품약관은 상품약관 열, 사업방법서는 사업방법서 열, 상품요약서는 상품요약서 열의 PDF 링크를 선택한다.
- 값이 "-"인 셀과 목록에 없는 문서에는 DOWNLOAD 단계를 생성하지 않는다.
- 2024.01.01 이전에 판매가 종료된 행은 DOWNLOAD 대상으로 생성하지 않는다.
- 2024.01.01 이전에 시작했더라도 해당 날짜 이후까지 이어지는 판매기간 행은 다운로드 대상에 포함한다.
- 각 DOWNLOAD의 target_description에는 대상 상품명, 판매기간 전체 문구, 판매기간 시작일, 상품코드, 문서명을 함께 적는다.
- 다른 판매기간 또는 상품코드 행의 동일한 문서명을 선택하지 않는다.
- 동일한 판매기간 행의 동일한 문서는 정확히 한 번만 다운로드한다.
- 서로 다른 행이 같은 파일명을 사용하더라도 각 행은 독립적인 DOWNLOAD 단계로 처리한다.
- 완료한 PDF 링크는 다시 클릭하지 않는다.

[PDF 클릭 및 다운로드 규칙]

- PDF 링크는 마우스 왼쪽 버튼으로 한 번만 클릭한다.
- PDF 링크를 클릭하면 브라우저에서 파일 다운로드가 즉시 시작된다.
- PDF 링크를 우클릭하거나 새 탭 또는 새 창으로 열지 않는다.
- PDF 미리보기 화면 또는 다른 이름으로 저장 창을 처리하는 단계를 생성하지 않는다.
- 다운로드가 완료될 때까지 다음 PDF 링크를 클릭하지 않는다.
- 다운로드 폴더에 새 파일이 생성되고 .crdownload 같은 임시 파일이 사라지면 완료된 것으로 판단한다.
- 다운로드가 시작되지 않은 경우에만 동일한 PDF 링크를 한 번 재시도한다.
- 재시도 후에도 실패하면 실패 로그와 현재 화면의 증적 이미지를 저장하고 다음 단계로 진행한다.
