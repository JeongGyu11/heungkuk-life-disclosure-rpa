판매상태: 판매중
대상 구분: 개인
보험유형: 전체
대상 상품: (무)흥국생명 다사랑3.10.5.5고당플러스간편건강보험(해약환급금미지급형V2)
수집 대상 기간: 2024.01.01 ~ 현재
공시 데이터 점검 결과: 현재 상품 공시 다운로드 표에 데이터 행 없음

현재 화면은 흥국생명 전체상품 화면이다.

다음 순서대로 정확히 수행한다.

1. 화면 왼쪽 전체상품 메뉴에서 판매상품 링크를 클릭한다.

2. 판매상품 화면의 [1. 구분선택] 영역에서 개인 링크를 클릭한다.

3. [2. 보험유형선택] 영역에서 전체 링크를 클릭한다.

4. [3. 판매상품명 선택] 영역에서
   (무)흥국생명 다사랑3.10.5.5고당플러스간편건강보험(해약환급금미지급형V2) 링크를 찾아 한 번 클릭한다.

5. 같은 화면 하단의 [4. 상품 공시 다운로드] 영역에
   (무)흥국생명 다사랑3.10.5.5고당플러스간편건강보험(해약환급금미지급형V2)이 선택되었는지 확인한다.

6. [4. 상품 공시 다운로드] 표에 판매기간 데이터 행이 없고
   판매기간, 상품코드, 상품약관, 사업방법서, 상품요약서 열 제목만 표시되는지 확인한다.

7. 데이터 행이 없는 현재 상태를 증적 이미지로 한 번 기록한다.

[DOWNLOAD 생성 규칙]

- 현재 확인된 표에는 판매기간 데이터 행이 없으므로 DOWNLOAD 단계를 생성하지 않는다.
- 표 머리글만 존재하는 경우 PDF 링크가 없는 것으로 판단한다.
- TIP 영역의 Adobe Reader 파일다운로드 링크는 상품 공시 문서가 아니므로 선택하지 않는다.
- 다른 상품의 판매기간, 상품코드 또는 PDF 링크를 대신 선택하지 않는다.
- 추측한 판매기간이나 상품코드로 DOWNLOAD 단계를 만들지 않는다.

[action_key 생성 규칙]

- DOWNLOAD 단계가 없으므로 download action_key를 생성하지 않는다.
- 존재하지 않는 문서에 대한 action_key를 추측하여 생성하지 않는다.

[작업 종료]

상품 선택과 공시 데이터 행 없음 확인 및 증적 기록이 완료되면 현재 화면을 유지한다.

오류로 처리하지 않고 이 상품의 작업을 완료 상태로 기록한다.

다음 프롬프트가 새로운 상품을 선택할 수 있도록 추가 PDF 링크를 클릭하지 않는다.
