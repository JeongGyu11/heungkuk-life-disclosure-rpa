# Heungkuk Life Disclosure RPA

흥국생명 공시실의 보험상품 PDF를 IPA 기반으로 자동 수집·저장하는 UiPath 프로젝트입니다.

상품별 LLM 작업 지시를 TXT 프롬프트로 관리하며, 실행 시 대상 상품에 맞는 프롬프트를 자동으로 교체해 상품 문서를 다운로드합니다.

## 저장소 구성

- `홍국생명_프로젝트/`: UiPath 워크플로와 브라우저 자동화 스크립트
- `홍국생명_프롬포트/`: 판매 상태·채널·상품별 LLM 프롬프트 TXT
- `홍국생명_프로젝트/Main.xaml`: 자동화 진입점
- `홍국생명_프로젝트/Load_Objective_From_Text.xaml`: 상품별 프롬프트 로딩
- `홍국생명_프로젝트/Scripts/`: UI 후보 수집 및 실행 보조 JavaScript

## 보안 및 저장소 정책

- API 키와 자격증명은 소스에 직접 저장하지 않습니다.
- 실행 증적, 화면 캡처, 다운로드 PDF, 로컬 UiPath 캐시 및 백업은 Git에서 제외합니다.
- LLM API 설정과 실행 환경별 경로는 외부 입력 또는 안전한 설정 저장소를 통해 전달합니다.

## 실행 전 확인

UiPath Studio에서 `홍국생명_프로젝트/project.json`을 열고 패키지를 복원한 뒤, 프롬프트 루트와 다운로드 경로를 실행 환경에 맞게 설정합니다.
